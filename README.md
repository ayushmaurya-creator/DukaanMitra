# DukaanMitra

**Ab dukaan ka hisaab, sirf bolkar!**

🌐 **Live Website:** 
https://ayushmaurya-creator.github.io/DukaanMitra/
DukaanMitra is an AI-powered Hindi voice assistant for small shopkeepers. Manage customer credit (udhaar), inventory, stock, sales, and daily business activities using simple voice commands.

## Features
- Hindi voice commands
- Customer and udhaar management
- Inventory and stock management
- Sales tracking
- Gemini AI integration
- Offline command fallback

## Technologies Used
- HTML
- CSS
- JavaScript
- Gemini API
- Cloudflare Workers
- GitHub Pages
